📊 스코어 설명

종합 점수 (Comprehensive Score)

📊 종합 점수란?

모든 지표를 가중 평균하여 계산한 단일 점수입니다. 높을수록 혼합이 잘 되고 있음을 의미합니다.

계산 공식: (Mixing Index × 40%) + (Flip Rate 점수 × 35%) + (Radial Uniformity × 25%)

🏆 등급 기준

S급 (90+): 완벽한 혼합 상태
A급 (75-89): 매우 좋은 혼합
B급 (60-74): 양호한 혼합
C급 (40-59): 개선 필요
D급 (0-39): 혼합 안됨

개별 지표

🔵 Mixing Index (각도 기반 혼합도)

드럼을 8개 구역으로 나눠 각 구역에서 A/B 입자 비율이 50:50에 가까운지 측정합니다. 100%면 완벽하게 섞인 상태입니다.

비유: 치킨 양념이 모든 부위에 골고루 묻었는지 확인하는 것과 같습니다.

🟢 Flip Rate (뒤집힘 빈도)

입자가 얼마나 자주 뒤집히는지 측정합니다. 높을수록 입자들이 활발하게 움직이고 있음을 의미합니다.

단위: flips/min (분당 뒤집힘 횟수)

비유: 프라이팬에서 재료가 얼마나 자주 뒤집어지는지 관찰하는 것입니다.

🟠 Radial Uniformity (반경 균일도)

중심부와 벽 근처에 A/B 입자가 균일하게 분포하는지 측정합니다. 100%면 모든 영역에 골고루 퍼진 상태입니다.

비유: 양념이 치킨 바깥쪽에만 묻지 않고 안쪽까지 잘 스며들었는지 확인하는 것입니다.

⚙️ 파라미터 설명

🥁 드럼 설정

Radius (반지름)

드럼의 크기를 조절합니다. 크면 더 많은 입자를 담을 수 있지만 혼합 효율이 달라질 수 있습니다.

Rotation (회전 속도, RPM)

분당 회전 수입니다. 높으면 빠르게 회전하고, 음수면 반대 방향으로 회전합니다.

🔩 배플 설정

Pattern (패턴)

Uniform: 균일하게 배치
Alternating: 기울기 교대 배치
Clustered: 그룹으로 모아 배치

Count / Length / Tilt

배플 개수, 길이, 기울기 각도입니다. 배플은 입자를 뒤집어주는 역할을 합니다.

⚪ 입자 설정

Count (개수)

시뮬레이션할 입자 수입니다. 많을수록 현실적이지만 성능이 저하됩니다.

Size / Friction

입자 크기와 마찰 계수입니다. 마찰이 높으면 잘 미끄러지지 않습니다.

⚛️ 물리 설정

Gravity Scale (중력 배율)

중력의 세기입니다. 2.0이면 2배 중력, 0.5면 절반 중력입니다.

Restitution (반발력)

충돌 시 튕기는 정도입니다. 1.0이면 완전 탄성 충돌(공처럼 튀김)입니다.

Air Friction (공기 저항)

공기 저항 계수입니다. 높으면 입자가 더 빨리 감속합니다.

Physics Quality (물리 정밀도)

충돌 계산 반복 횟수입니다. 높으면 정확하지만 느려집니다.
